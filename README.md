# TechNews Today

## 📌 Sobre o Projeto

O **TechNews Today** é uma página web fictícia criada para apresentar novidades e conteúdos relacionados ao mundo da tecnologia. O projeto utiliza **HTML5 e CSS3**, com uma estrutura simples, organizada e visualmente moderna.

A página apresenta uma notícia em destaque sobre Inteligência Artificial, uma seção de vídeo e um formulário para inscrição em uma newsletter.

## 🎯 Objetivo

O objetivo do projeto é praticar a criação de uma página web utilizando **HTML semântico** e **CSS**, trabalhando com organização de conteúdo, formulários, vídeos incorporados e estilização.

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* YouTube para incorporação do vídeo

O arquivo HTML utiliza elementos como `<header>`, `<main>`, `<article>`, `<section>` e `<footer>` para organizar o conteúdo da página.

## 💻 Funcionalidades

### 📰 Notícia em destaque

A página possui uma notícia chamada **"IA Revoluciona Desenvolvimento"**, com data, texto introdutório e uma opção de **"Leia mais"** utilizando o elemento `<details>`.

### 📺 Vídeo

Foi adicionada uma seção **"Tech em Vídeo"**, contendo um vídeo incorporado do YouTube por meio de um `<iframe>`.

### 📧 Newsletter

O projeto possui um formulário de inscrição em newsletter, no qual o usuário pode informar seu e-mail, escolher uma área de interesse e aceitar os termos antes de realizar a inscrição.

As áreas disponíveis são:

* Inteligência Artificial
* Desenvolvimento Mobile
* Tecnologias Web

## 🎨 Estilização

O CSS utiliza um tema escuro, com tons de roxo, azul, rosa e laranja. A página também utiliza **CSS Grid**, gradientes, bordas arredondadas e diferentes estilos para os elementos.
A newsletter recebe um fundo roxo e o botão de inscrição utiliza um gradiente entre laranja e vermelho.

## 🚀 Como Executar

1. Baixe ou clone o projeto.
2. Mantenha os arquivos `desafio10a.html` e `10a_desafio.css` na mesma pasta.
3. Abra o arquivo `desafio10a.html` em um navegador.
4. A página será exibida com todos os estilos aplicados.
